# Практична робота №6

Гринишин Вікторія ІПЗс-24-2

Тема: Проєктування користувацьких інтерфейсів веб-додатків: моделювання станів екрана (Screen States) та архітектура дизайн-систем на основі дизайн-токенів.

## Висновок

Під час виконання практичної роботи було розширено SPA-застосунок ARTBOARD та реалізовано чотири основні стани екрана: завантаження (Loading), відображення даних (Content), порожній стан (Empty) і стан помилки (Error). Для перевірки станів створено панель керування, функцію `renderState(stateName)`, імітацію асинхронного завантаження за допомогою `window.setTimeout()`, пошук робіт і відновлення початкового списку.

Також впроваджено дизайн-систему з трирівневою ієрархією CSS-токенів: Primitive, Semantic та Component. Створено окремий файл `tokens.css` і розділ UI-Kit, у якому продемонстровано кнопки Primary, Secondary та Danger, поля введення з різними станами, а також картку контенту. Перемикання світлої та темної тем реалізовано через семантичні токени без зміни структури компонентів.

У результаті роботи закріплено навички моделювання станів інтерфейсу, роботи з DOM, CSS Custom Properties та побудови узгодженої дизайн-системи засобами Vanilla JavaScript і CSS.
